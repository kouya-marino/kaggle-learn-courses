# What Is Feature Engineering

*Feature Engineering — lesson 1* · [Tutorial on Kaggle](https://www.kaggle.com/code/ryanholbrook/what-is-feature-engineering)

## Key ideas

- Feature engineering makes data better suited to the model (e.g. ratios for a linear model).
- Establish a baseline score first so every change can be measured.
