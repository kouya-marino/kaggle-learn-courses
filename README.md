## Layout

```
NN-Course-Name/
├── README.md                  course overview and lesson index
├── certificate.png            course completion certificate
└── NN-Lesson-Name/
    ├── tutorial.ipynb / .md   lesson tutorial
    ├── exercise.ipynb / .md   exercise as provided
    ├── exercise-solved.ipynb / .md   exercise with my answers
    └── notes.md               key ideas, functions used and answers
```

Lessons without an exercise contain only the tutorial and notes.
